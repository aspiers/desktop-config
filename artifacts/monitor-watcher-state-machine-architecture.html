Architectural boundaries

Layer Owns Must not do
Observation adapter One canonical, immutable sysfs/XRandR/autorandr sample Authorize actions from torn evidence
Pure reducer Transitions, timers, retry policy, deduplication Perform display or process I/O
Action dispatcher Durable admission and keyed worker lifecycle Infer desired topology
Persistence + scheduler Atomic state, restart recovery, nearest monotonic wake-up Abandon unresolved external displays

Controller state diagram

stateDiagram-v2
  [*] --> RECOVERING

  RECOVERING --> FINALIZING: keyed finalizer still running / reattach
  RECOVERING --> VERIFYING: exact current profile / restart proof
  RECOVERING --> DISCOVER_FAST: new or changed evidence
  RECOVERING --> WAIT_SLOW: restore unresolved expired deadline

  QUIESCENT --> QUIESCENT: same exact stable profile
  QUIESCENT --> VERIFYING: another exact current profile
  QUIESCENT --> DISCOVER_FAST: meaningful change or EDID loss

  DISCOVER_FAST --> DISCOVER_FAST: invalid or incomplete sample / fast timer
  DISCOVER_FAST --> APPLY_PENDING: eligible target differs / persist admission
  DISCOVER_FAST --> VERIFYING: target already exact, active, current
  DISCOVER_FAST --> WAIT_SLOW: 30 s aggressive deadline reached
  DISCOVER_FAST --> UNSUPPORTED: complete unknown identity stable 10 s

  APPLY_PENDING --> APPLY_PENDING: dirty event / re-observe admission
  APPLY_PENDING --> APPLYING: keyed worker accepted
  APPLYING --> VERIFYING: success + exact re-observation
  APPLYING --> DISCOVER_FAST: success but still changing
  APPLYING --> APPLY_FAILED: failure or unknowable outcome
  APPLY_FAILED --> APPLY_FAILED: unchanged evidence / never repeat
  APPLY_FAILED --> DISCOVER_FAST: genuinely changed evidence

  WAIT_SLOW --> WAIT_SLOW: unresolved / 5, 10, 20, 30 s capped polling
  WAIT_SLOW --> DISCOVER_FAST: evidence changes / reset fast backoff
  WAIT_SLOW --> APPLY_PENDING: target becomes eligible
  WAIT_SLOW --> VERIFYING: target becomes exact/current

  VERIFYING --> VERIFYING: continuous proof younger than 10 s
  VERIFYING --> DISCOVER_FAST: event, contradiction, inactive or extra output
  VERIFYING --> QUIESCENT: stable profile equals finalized profile
  VERIFYING --> FINALIZE_PENDING: stable profile differs / admit transaction

  FINALIZE_PENDING --> FINALIZE_PENDING: dirty event / re-authorize exact key
  FINALIZE_PENDING --> FINALIZING: keyed finalizer accepted
  FINALIZING --> FINALIZING: running or result pending / no relaunch
  FINALIZING --> QUIESCENT: success tombstone + fresh valid confirmation
  FINALIZING --> DISCOVER_FAST: topology changed / stop stale worker
  FINALIZING --> FINALIZE_FAILED: finalizer failure
  FINALIZE_FAILED --> FINALIZE_FAILED: same transition / never repeat ID
  FINALIZE_FAILED --> DISCOVER_FAST: genuine new topology or profile

  UNSUPPORTED --> UNSUPPORTED: same complete unknown topology / 60 s health tick
  UNSUPPORTED --> WAIT_SLOW: identity becomes incomplete
  UNSUPPORTED --> DISCOVER_FAST: eligible profile or proven unplug

Primary transition path

sequenceDiagram
  participant H as Hub / display
  participant W as Watcher scheduler
  participant O as Observation adapter
  participant R as Pure reducer
  participant A as Autorandr worker
  participant F as Desktop finalizer
  participant P as Persistent state

  H-->>W: DRM event (wake-up hint)
  W->>O: Probe canonical evidence
  O-->>R: External connected, EDID unresolved
  R->>P: DISCOVER_FAST + deadline
  loop Fast retries until 30 s
    W->>O: Timer-driven probe
    O-->>R: Updated evidence
  end
  R->>P: WAIT_SLOW (intent preserved)
  loop Persistent capped polling
    W->>O: 5/10/20/30 s probe
    O-->>R: EDID/profile now eligible
  end
  R->>P: APPLY_PENDING + application key
  R->>A: autorandr --load selected profile
  A-->>W: Completion
  W->>O: Drain events and re-probe
  O-->>R: Exact + active + current
  R->>P: VERIFYING
  W->>O: Continuous proof probes for 10 s
  O-->>R: Stable exact evidence
  alt Profile already desktop-finalized
    R->>P: QUIESCENT (no desktop relayout)
  else Genuine desktop transition
    R->>P: FINALIZE_PENDING + unique ID
    R->>F: Start keyed setup-monitor oneshot
    F-->>W: Success
    W->>O: Fresh confirmation probe
    O-->>R: Same transition key still valid
    R->>P: Commit desktop-finalized profile, then QUIESCENT
  end

Safety invariants

  1. Never apply laptop-only while external hardware is present.
  2. Never infer unplug from temporary EDID absence.
  3. Never repeat an application for unchanged (physical epoch, target, observation) evidence.
  4. Never finalize before 10 seconds of continuous exact/current/active proof.
  5. Never equate autorandr application with completed desktop finalization.
  6. Never abandon an unresolved connected external topology: a future timer always exists.
  7. Invalid/torn observations preserve admitted/running/completed action evidence and only schedule re-observation.
  8. Failed or cancelled finalization IDs are never reused.
