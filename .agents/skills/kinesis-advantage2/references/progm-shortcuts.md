# Advantage2 Progm shortcuts

From the [Advantage2 User's Manual][manual], sections 6 and 7. "PUM" means
Power User Mode must be on.

| Shortcut | Effect |
| --- | --- |
| Progm+Esc | Status report, typed into the focused window |
| Progm+Shift+Esc | Toggle Power User Mode (LEDs flash 4x on, 2x off) |
| Progm+F1 | Open or close the v-drive (PUM). Unmount before closing |
| Progm+PrintScrn while plugging in | Open the v-drive at plug-in |
| Progm+F2, then a key | Create hotkey layout `<key>_qwerty.txt`, a copy of the active layout (PUM, v-drive closed) |
| Progm+`<hotkey>` | Load that hotkey layout |
| Progm+F3 / Progm+F4 | Load QWERTY / Dvorak |
| Progm+F5 / F6 / F7 | Mac / PC / Windows thumb mode; erases custom thumb-key remaps in the active layout |
| Progm+F8 | Toggle key clicks |
| Progm+Shift+F8 | Toggle special action tones (Caps/Num/Scroll Lock, Keypad, Insert) |
| Progm+Shift+F9 | Soft reset: erase remaps and macros in the active layout |
| Progm+F9 while plugging in | Hard reset: erase `qwerty.txt`, `dvorak.txt`, `state.txt`; QWERTY, Windows mode |
| Progm+F12 while plugging in | Rescue: start without reading layout files |
| Progm+F10, then 0-9 | Global macro playback speed (0 disables macros) |
| Progm+F11 | Record a macro: trigger, contents, then Progm |
| Progm+F12 | Onboard remap: source action, destination key, repeat, then Progm. Tap a key twice to restore it |

[manual]: https://kinesis-ergo.com/wp-content/uploads/Adv2-Users-Manual-01-07-19_us.pdf
