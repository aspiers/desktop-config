AeroSpace Thumb Keys

Every AeroSpace binding runs through Karabiner’s Thumb layer, which calls the aerospace command. AeroSpace itself has no key bindings in this setup.

Modifiers on the MacBook keyboard

Thumbhold right ⌘
Ctrlleft ⌘ (the Control position)
Altleft ⌥
Shifteither ⇧

Letters mean the letter typed, not the label on the key: on the built-in keyboard the left-hand letters sit one key to the left, so Q is the § key, A is Caps Lock, R is the E key. On the Advantage 360, Thumb is the key with the Windows keycap on the right thumb pad and Ctrl is its left Ctrl key.

Known issue: Thumb + Ctrl bindings do nothing from the laptop keyboard while an ordinary app such as Chrome is in front. They work from the Kinesis, and from the laptop in terminals, Emacs and Orca.

Focus and move windows

Thumb+←↑↓→ Focus the window in that directionThumb + Ctrl + arrows does the same
Thumb+Shift+←↑↓→ HJKL Move the window one tile that way
Thumb+Alt+Shift+←↑↓→ HJKL Join with the neighbourPuts both windows in a new container
Thumb+/ Next window on the workspace, wrapping roundThumb + Ctrl + / does the same
Thumb+Shift+/ Previous window on the workspace
Thumb+Alt+Return Window pickerFrom mac-jump, not AeroSpace
Thumb+Tab Chrome tab picker, every tabFrom mac-jump, not AeroSpace

Workspaces

Thumb+1–6 Go to workspace 1–6
Thumb+Alt+1–6 Send the window to workspace 1–6 and follow it
Thumb+, . Previous / next workspaceSteps through 1–6, empty ones included, stopping at either end
Thumb+Alt+, . Send the window to the previous / next workspace and follow it

Monitors

Thumb+Shift+, . Focus the other monitorPrevious / next, wrapping round, however the monitors are arranged
Thumb+Alt+Shift+, . Send the window to the other monitor and follow itPrevious / next, as above
Thumb+Alt+Shift+1–3 Send the window to monitor 1–3 and follow it

Window state

No Thumb needed once you’re in. Q, Esc or Space leaves.

Pass-through mode: Thumb + Ctrl + P

Right ⌘ stops being Thumb and reaches apps as plain ⌘, for apps that need it. Press Q to leave.

Free mouse mode: hold D + F

As fievel on Linux, without Thumb. The keys below work while the mode is on.

D+F hold: free mouse mode, while held
Z lock the mode on / off, so D + F can be let go
J K I L move left, down, up, right
Space left click
; right click
A hold: move slowly
S hold: move fast
N M , . scroll left, down, up, right
,+M together: Home
N+. together: End

Grid mode: Thumb + -

Jumps the pointer within the focused window, like Neru's grid. Nothing is drawn: the window is split into thirds like a numpad.

U I O top row of cells
J K L middle row
M , . bottom rowEach press narrows within the last cell, three levels deep
Space ; left / right click, and leave
Return Esc leave, pointer staysAny other key also leaves, then acts as usual

Where new windows land

1 main monitor
Orca, Emacs, Chrome, Terminal, iTerm2, kitty, Ghostty
2 main monitor
Nothing automatic. Chrome windows for 2 land on 1: send them with Thumb + Alt + 2
3 main monitor
Firefox, Notion, LM Studio
4 main monitor
Slack, Telegram, Discord, Beeper, Zulip, Teams, Outlook
5 main monitor
Nothing automatic. Chrome windows for 5 land on 1: send them with Thumb + Alt + 5
6 main monitor
Activity Monitor, Chrysalis
S secondary monitor
Stands in for Linux’s sticky windows. No number key: reach it with Thumb + Shift + , or .

When docked, the external monitor is the main one (the display with the menu bar) and the laptop screen is secondary. Undocked, every workspace is on the laptop screen. System Settings windows always float.
